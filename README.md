# ImmortalWrt-C8-660-CI

NRadio C8-660 (MediaTek MT7981) 专用 ImmortalWrt 固件编译 CI。

基于 [immortalwrt/immortalwrt](https://github.com/immortalwrt/immortalwrt) master 分支编译。

## 使用方式

在 Actions 页面手动触发 `C8-660` 工作流即可编译。

## 目录结构

- `workflows/` —— CI 工作流配置
- `Scripts/` —— 编译自定义脚本
- `Config/` —— 设备与通用配置
